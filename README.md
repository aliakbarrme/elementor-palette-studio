## ✨ Features

- 🎯 5 harmonies: complementary, analogous, triadic, split, monochrome
- 🌗 Light or dark website backgrounds
- 🔤 12 hand-picked Google Font pairs (heading / body)
- 👀 Live preview on a real hero + cards section
- ♿ WCAG contrast check for text and buttons
- 📋 Copy **CSS variables** or **Elementor Site Settings** (Global Colors & Fonts) in one click
- 🎲 *Surprise me* for instant inspiration

## 🚀 Why I built it

Every Elementor project starts with Site Settings → Global Colors & Fonts. This turns a client's logo color into a complete, accessible system in seconds.

## 🛠️ How to use

1. Open the **[live demo](https://aliakbarrme.github.io/elementor-palette-studio/)**
2. Pick the brand color, harmony and font pair
3. Copy the values into Elementor → Site Settings

To run it locally, download `index.html` and open it in any modern browser. No build step, no server.
